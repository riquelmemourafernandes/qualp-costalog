# Importação de praças e tarifas

Não importar valores sem origem verificável. Para cada praça/tarifa, guardar nome, rodovia, UF, coordenadas WGS84, categoria veicular, regra de eixos, valor, vigência, órgão/concessionária, URL da fonte e data de coleta.

## Processo recomendado
1. Identificar a fonte oficial (ANTT, agência estadual ou concessionária).
2. Arquivar o arquivo ou URL original e registrar a data de consulta.
3. Validar categorias, eixos suspensos, descontos e regras específicas da concessão.
4. Importar em ambiente de teste e comparar amostras manualmente.
5. Publicar após revisão, mantendo histórico das tarifas anteriores.

A base inicial está vazia. Não criar tarifas fictícias para preencher lacunas.
